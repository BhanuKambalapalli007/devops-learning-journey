## Key commands mastered so far
| Command | Purpose |
|---|---|
| `git init` | Initialise a new repository |
| `git add -p` | Partial staging |
| `git commit --amend` | Fix last commit message |
| `git reset --soft` | Undo commit, keep changes staged |
| `git restore` | Discard working directory changes |
| `git push / pull` | Sync with GitHub |
