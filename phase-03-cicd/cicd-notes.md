
# CI/CD Notes — Phase 03

## What is CI/CD?

CI (Continuous Integration) automatically builds and tests code on every push.

CD (Continuous Delivery/Deployment) automatically deploys tested code.

## Why it matters in DevOps

- Catch bugs before they reach production

- Deploy faster and more frequently

- Every git push triggers the pipeline

## Tools to learn

- GitHub Actions — pipeline as YAML config

- Jenkins — industry standard CI server

- Docker — build consistent container images in pipelines
