## Repository structure

All phases are organised as separate folders. Each folder contains
a README with status and topics, plus notes and reference documents.

phase-01-git contains three weekly reference documents covering
all Git fundamentals, branching, merging, rebase, hooks, GitHub
Actions, bisect, and GitFlow learned across 21 days.

---

## Phase 01 Git skills demonstrated

Fundamentals: repository setup, staging area, partial staging
with git add -p, reading diffs, gitignore configuration.

Undoing and recovery: git restore, git reset soft mixed hard,
git revert, git reflog for recovering lost work and deleted branches,
git bisect for binary search bug hunting.

Branching and collaboration: feature branch workflow,
fast-forward and 3-way merges, merge conflict resolution,
git rebase for linear history and interactive cleanup.

Remote and team workflow: SSH key authentication, GitHub remote
setup, Pull Requests, code review, branch protection rules,
GitFlow with version tags v1.0.0 and v1.0.1, trunk-based
development with short-lived branches.

Automation: git hooks pre-commit commit-msg pre-push,
GitHub Actions CI pipeline running on every push to main.
